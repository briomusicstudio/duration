# Музичні тривалості

Інтерактивно вивчай музичні тривалості, ноти й ритми українською мовою. На сайті є дерево тривалостей, музична математика, ритмічні завдання, лабіринт і перегони.

## Публікація через GitHub Pages

1. Створіть GitHub-репозиторій і завантажте до нього `index.html` та `favicon.svg`.
2. Відкрийте **Settings → Pages** у репозиторії.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**, потрібну гілку та папку `/ (root)`, потім збережіть налаштування.
4. Дочекайтеся завершення публікації та відкрийте адресу, яку покаже GitHub Pages.

Сайт не потребує збірки. React, Babel, Tailwind CSS і шрифт Nunito зараз завантажуються із зовнішніх CDN, тому для роботи сторінки потрібне підключення до інтернету.

## Пошукова оптимізація

Українські метадані сторінки, назва вкладки, іконка та структуровані дані розміщені в `index.html`. Канонічну адресу сторінки й `og:url` варто додати після публікації, коли буде відома постійна URL-адреса GitHub Pages.
